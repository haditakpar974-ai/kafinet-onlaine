# پروژه کافی‌نت آنلاین

وب‌سایت فارسی و واکنش‌گرا برای معرفی خدمات کافی‌نت و ثبت اولیه درخواست‌ها.

## فایل‌ها
- `index.html` صفحه اصلی سایت
- `style.css` ظاهر و چیدمان واکنش‌گرا
- `script.js` منوی موبایل و آماده‌سازی فایل درخواست
- `assets/` محل قرار دادن تصاویر و فایل‌های آینده

## پیش‌نمایش محلی
فایل `index.html` را در مرورگر باز کنید. برای نمایش فونت Vazirmatn اتصال اینترنت لازم است؛ در صورت نبود اینترنت، فونت پیش‌فرض دستگاه استفاده می‌شود.

## انتشار با GitHub Pages
1. فایل ZIP را در گوشی استخراج کنید.
2. وارد مخزن GitHub خود شوید.
3. فایل‌های داخل پوشه پروژه (`index.html`، `style.css`، `script.js` و `README.md`) را بارگذاری کنید؛ خود فایل ZIP به‌تنهایی سایت را اجرا نمی‌کند.
4. روی **Commit changes** بزنید.
5. در مخزن به **Settings → Pages** بروید.
6. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید، شاخه `main` و پوشه `/(root)` را مشخص و ذخیره کنید.
7. پس از چند دقیقه، آدرس سایت در همان صفحه Pages نمایش داده می‌شود.

## مهم
- فرم فعلی اطلاعات واردشده را به شکل یک فایل متنی دانلود می‌کند؛ اطلاعات را به‌طور خودکار برای صاحب سایت ارسال نمی‌کند.
- برای دریافت آنلاین سفارش‌ها باید فرم را به بک‌اند یا سرویس فرم مورداعتماد متصل کنید.
- اطلاعات حساس مثل رمز عبور، کد یک‌بارمصرف و اطلاعات بانکی را از کاربران نخواهید.
- متن‌ها، شماره تماس و جزئیات کسب‌وکار را پیش از انتشار مطابق اطلاعات واقعی خودتان تغییر دهید.
